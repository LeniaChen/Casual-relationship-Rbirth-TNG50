# Selection R_7_10 (main selection)

7 < R < 10 kpc, |z| < 0.3 kpc, bound with all orbit quantities, birth radius < 20 kpc, [Fe/H] > −0.5, J_z > 0 — the selection of the paper and of the main result.

This folder only mirrors `results/TNG/causal_graph/` and `results/TNG/truth_comparison/` (identical scripts and figures), so that all four selections in `star_condition/` have the same layout. The inputs are `data/rlcd_input/{nonoise,noise}/` (public, `bash tools/unpack_data.sh`), and the analysis results are in `results/rlcd_A/identifiability/`.
